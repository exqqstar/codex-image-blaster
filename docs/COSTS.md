# Costs and provider selection

Local bible authoring, validation, plans, box guides and gallery use Node built-ins
and make no network calls. Codex native image tools use the session's actual
entitlement and limits; this project does not provide free/unlimited generation.

World Labs/Marble and FAL are optional, externally billed providers. World Labs
requires its API key/credits for splats. FAL is used by preserved image edit,
Hunyuan/Meshy model and SFX scripts. Keys are not required for tests or native
comic references. Configuring a key does not select or authorize that provider.

Default to requested reference views first. Avoid generating every detected
object; keep furniture/props in scene canon unless the user needs separate GLBs.
Clean plates remove explicit unwanted items, not all objects by default.

Before paid work, state provider, assets/call count and stop conditions. Use
existing authorization; seek approval only for a newly introduced spend/provider.
Stop on auth/quota/billing errors or repeated failure. Do not automatically
reroute a missing native image tool to World Labs/FAL or retry expensive calls.
Current prices/quotas belong to the provider; check them at the time of use.
